Про нас

Головна суть проєкту — зробити загальний сайт групи, де у кожного студента є своя картка з фотографією та посиланням на особисте портфоліо.

Що ми для цього робили:

  • Писали базовий код на HTML (робили собі сторінки-візитки).
  • Вчилися закидати код на GitHub через термінал (робили гілки, коміти та Pull Request-и, щоб нічого не зламати).
  • Використовували дошку в Trello, щоб брати собі завдання і бачити, хто що зараз робить.



Ми навчаємося на спеціальності комп'ютерні науки (F3), на цій спеціальності готують фахівців у сфері інформаційних технологій,
які мають навички розробки програмних продуктів, розуміють принципи роботи з
базами даних та штучним інтелектом, вміють розв’язувати задачі, пов’язані з математичним
моделюванням та розбираються в різних операційних системах.

Інформація про предмет

Інструментальні засоби програмування — це програмне забезпечення, яке допомагає розробникам створювати, тестувати та підтримувати програмні системи. Вони забезпечують різноманітні інструменти для автоматизації та оптимізації процесу розробки програмного забезпечення.

Список тем курсу:

  • Лекція 1: Вступ до курсу. Поняття інформаційної системи, їх властивості та класифікація. Функції інструментальних засобів. Архітектура, проблеми сполучення, базові та прикладні засоби. Парадигми програмування.
  • Лекція 2: Системи контролю версій: Git, SVN, Mercurial. Інструменти співпраці: GitHub, GitLab.
  • Лекція 3: Основи Git. Команди, робота з гілками, конфлікти, історія змін, віддалені репозиторії.
  • Лекція 4: Інтегровані середовища розробки (IDE) — можливості та функції.
  • Лекція 5: Автоматизація розробки (CI/CD): Jenkins, GitHub Actions, GitLab CI/CD, хмарні платформи.
  • Лекція 6: Тестування та якість: JUnit, PHPUnit, Selenium, статичний аналіз коду.
  • Лекція 7: Методології: Agile, Scrum, Kanban. Управління проєктами: Jira, Trello, Asana.
  • Лекція 8: Інструменти документації: Markdown, Sphinx, Swagger. Інтеграція документації в розробку.
  • Лекція 9: Бібліотеки та фреймворки. Прискорення розробки, робота з UI, мережею та даними.
  • Лекція 10: Розвиток інструментальних засобів. Методи дослідження, тенденції в ІТ.
